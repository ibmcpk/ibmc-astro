## Onscreen assessment player

The eAssessment Player is the application MYP students use to open and complete exams on a computer. Download the version for your operating system:

### Windows

[https://eassessment.ibo.org/player/windows](https://eassessment.ibo.org/player/windows)

### Mac

[https://eassessment-admin.ibo.org/player/mac](https://eassessment-admin.ibo.org/player/mac)

Any 5 digit number can be used as the school code upon starting it for the 1st time.
